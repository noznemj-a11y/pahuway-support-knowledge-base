# Pahuway Support Knowledge Base

A customer support knowledge base for the front-desk and guest-support team at Pahuway, a boutique seaside hotel. It gives new support agents clear, step-by-step guidance for common guest situations, plus ready-to-use reply templates.

> **Important:** Pahuway is a **fictional hotel created for portfolio purposes**. It is not affiliated with any real business. All policies, prices, dates, room types, phone numbers, and email addresses in this project are invented. Contact details use example.com addresses and obviously fake phone numbers.

## How the articles are organized

- **[articles/](articles/)** contains one Markdown file per support topic. Every article follows the same structure so you always know where to look:
  1. **Purpose**: what the article covers.
  2. **When to use this article**: the situations it applies to.
  3. **Steps**: a numbered procedure to follow.
  4. **What to say to the guest**: a short sample reply.
  5. **When to escalate**: the point at which you hand the case to someone else.
  6. **Related articles**: links to other articles you may also need.
  7. **Last reviewed**: the (made-up) date the article was last checked.
- **[templates/](templates/)** contains reusable reply templates. Fill in the `[brackets]` and adjust the wording to fit the guest's situation.
